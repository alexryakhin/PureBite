# Pure Bite

Marketing site for **Pure Bite** — intermittent fasting tracker for iOS (App Store ID `6505026086`).

Live: [alexriakhin.com/PureBite](https://alexriakhin.com/PureBite)

## Product

Stick to intermittent fasting with a live window timer (16:8 and more), streaks, optional reminders, and recipes when the eating window opens. Not a calorie diary.
